5. Other objects in the model
Objects inside the height range below (a stage, truss tower, pillar, table, planter…) block the chairs under them. Other banks' chairs and your aisle markers are never treated as objects, so aisles still work as floor-level markers. With automatic updates on, moving an object re-lays the seating.
An object blocks chairs if any part of it lies between the two handles. Low handle: ignore anything lower than this (rugs, cables, kerbs). High handle: ignore anything that starts higher than this (trusses, banners, canopies).
Use Ignore for things that should not block (ground, terrain, a venue shell). With automatic updates ticked, moving or editing an object re-lays the banks it affects; otherwise press Refresh.
4. Aisles (shared by every bank)
Draw flat faces for aisles and gangways, loose or inside groups (any shape; they can run across several banks). Mark them as aisles and every bank they overlap keeps chairs clear of them, now and as you edit or move them. Aisles are saved in the model.
